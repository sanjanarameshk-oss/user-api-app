# User API App

A simple React application that retrieves and displays user information from an API using `useEffect()` and `fetch()`.

## Features

* Fetches users from JSONPlaceholder API
* Uses `useState()`
* Uses `useEffect()`
* Displays User ID
* Displays Name
* Displays Username
* Displays Email
* Shows `Loading...` while fetching
* Shows an error message if the API request fails

## API Used

https://jsonplaceholder.typicode.com/users
